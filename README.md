# comp584_project5_nimbus4000

Nimbus 4000 is a responsive weather dashboard that retrieves forecast data from the National Weather Service API.

Features:
-Weather forecasts for four U.S. cities
-Temperature, weather conditions, and wind information
-Six upcoming forecasts periods with NWS weather icons
-Animated weather and forecast cards
-Responsive pastel themed interface

Technologies:
-HTML5
-CSS3 (grid, Flexbox, media queries)
-JavaScript (Fetch API, DOM manipulation)
-National Weather Service API: https://api.weather.gov/
-Motion for JS: https://motion.dev/

Animation Methods:
-animate() | Animates the main weather card and forecast cards
-stagger() | Creates sequential animations for forecast cards
